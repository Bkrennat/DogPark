# DogPark project

Pages separees :
- `index.html` : Home
- `html/parks.html` : Parks
- `html/events.html` : Events
- `html/park-info.html` : Parks infos
- `html/blog.html` : Blog
- `html/aboutus.html` : About Us
- `html/contact.html` : Contact

Dossiers :
- `css/` : styles par page et styles globaux
- `images/` : images du site
- `js/partials.js` : chargement de la navbar et du footer
- `partials/` : navbar et footer partages

Le projet utilise Bootstrap, Bootstrap Icons et Google Fonts via CDN.
Lance `index.html` avec l'extension VS Code Live Server ou un serveur local.
