# DogPark project

Pages séparées :
- `index.html` : Home V2
- `parks.html` : Parks V2
- `events.html` : Events V2
- `park-info.html` : Parks infos V2
- `blog.html` : Blog
- `navbar-v2.html` : Navbar V2

CSS séparés :
- `css/base.css` : styles globaux
- `css/navbar.css` : navbar
- `css/footer.css` : footer
- `css/home.css` : page Home
- `css/listing.css` : pages Parks et Events
- `css/events.css` : petits styles spécifiques Events
- `css/park-info.css` : page détails du parc
- `css/blog.css` : page Blog
- `css/navbar-demo.css` : frame Navbar V2

Le projet utilise Bootstrap, Bootstrap Icons et Google Fonts via CDN.
Lance `index.html` avec l'extension VS Code Live Server.
